# GitHub Setup and Submission Instructions

Follow these steps before beginning the assignment.

## 1. Create Your Repository from the Template

1. Open the assignment template repository in GitHub.
2. Near the top of the page, click **Use this template**.
3. Click **Create a new repository**.
4. Choose your GitHub account as the owner.
5. Name the repository using this format:

```text
lastname-cpw102-tiered-phone-plan-calculator
```

Example:

```text
smith-cpw102-tiered-phone-plan-calculator
```

6. Set the repository visibility to **Private**.
7. Click **Create repository**.
8. In your new repository, go to Settings.
9. Select Collaborators.
10. Click Add people.
11. Search for and add `@rachelkingCPTC` as a collaborator.
12. Make sure the invitation is sent before submitting the assignment.

---

## 2. Clone the Repository with GitHub Desktop

You need a local copy of the repository before editing the project files.

1. Open your repository on GitHub.
2. Click the green **Code** button.
3. Click **Open with GitHub Desktop**.
4. Choose where you want the project saved on your computer.
5. Click **Clone**.

You now have a local copy of the repository.

---

## 3. Create a Development Branch

Create a branch **before editing any assignment files**.

In GitHub Desktop:

1. Click **Current branch**.
2. Click **New branch**.
3. Name the branch:

```text
development
```

4. Click **Create branch**.
5. If GitHub Desktop asks whether you want to publish the branch, click **Publish branch**.

Your current branch should now be `development`.

Do not complete the assignment directly on `main`.

---

## 4. Open the Project in Visual Studio Code

In GitHub Desktop:

1. Make sure **Current branch** shows `development`.
2. Click **Repository** in the menu bar.
3. Click **Open in Visual Studio Code**.

Visual Studio Code should open the project folder.

You are now ready to begin the assignment.

---

## 5. Commit and Push Your Work

As you work, save your progress with commits.

In GitHub Desktop:

1. Review the files listed under **Changes**.
2. Enter a short summary describing the work you completed.
3. Click **Commit to development**.
4. Click **Push origin** to upload your commits to GitHub.

Make additional commits as needed while completing the assignment.

---

## 6. Create a Pull Request

When the assignment is complete and all changes have been pushed:

1. Open your repository on GitHub.
2. Click the **Pull requests** tab.
3. Click **New pull request**.
4. Set the branches so that:

```text
base: main
compare: development
```

5. Review the listed changes.
6. Click **Create pull request**.
7. Enter a short title describing the completed assignment.
8. Add a brief description.
9. Click **Create pull request**.

---

## 7. Submit the Pull Request

Leave the pull request open for review; do not merge it. Submit its URL to the Canvas assignment.
